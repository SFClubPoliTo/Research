# Figures 🖼️

Curated charts generated by the Monte Carlo reproducibility script.

## 📄 Files

| File | Description |
| --- | --- |
| `lcg_uniform_histogram.png` | Diagnostic histogram for the pseudo-random uniform generator example. |
| `box_muller_qq_plot.png` | Q-Q diagnostic for normal samples generated through the Box-Muller transform. |
| `european_call_convergence.png` | Convergence path for the European call Monte Carlo estimator. |
| `asian_call_mc_vs_qmc.png` | Standard Monte Carlo versus randomized (scrambled Sobol) quasi-Monte Carlo for an Asian call at equal cost, with 95% intervals. |
| `terminal_wealth_distribution.png` | Simulated terminal-wealth distribution used in the portfolio risk example, with the 5% wealth quantile and the VaR loss. |

## 🔁 Regeneration

From the project root:

```bash
python examples/run_reproducibility.py
```
