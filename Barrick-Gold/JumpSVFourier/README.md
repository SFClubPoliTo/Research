# Beyond Black-Scholes Synthetic Examples 🚀

📄 Article PDF: https://sfclubpolito.it/pdf-viewer.html?file=Pubblicazioni%2FBeyond%20Black-Scholes%20-%20Jumps%20%26%20Stochastic%20Volatility.pdf&lang=it

This folder provides reproducible synthetic examples for the Starting Finance Club PoliTo Research article on jump processes, stochastic volatility, and Fourier methods.

## 👥 Authors

- [Davide Sisto](https://github.com/sistox5)
- Matteo Armando

## 🎯 Purpose

The examples connect the theoretical discussion to small simulated illustrations. They do not calibrate market data and they are not intended as an option-pricing benchmark.

## 🗂️ Structure

| Path | Role |
| --- | --- |
| `1 Simulations/simulate_examples.py` | Generates synthetic data and article figures. |
| `1 Simulations/fourier_pricing_check.py` | Heston and Merton call prices: characteristic-function (Fourier) prices versus Monte Carlo and the Merton series. |
| `1 Simulations/img/` | Article-ready figure files generated by the script. |
| `1 Simulations/output/` | CSV files with simulated paths and variance examples. |
| `requirements.txt` | Minimal Python dependencies for the simulation scripts. |

## ⚙️ Setup

```bash
pip install -r requirements.txt
```

## ▶️ Run

From this folder:

```bash
python "1 Simulations/simulate_examples.py"
python "1 Simulations/fourier_pricing_check.py"
```

## 🛠️ Corrections (24 October 2026)

An audit found two errors in the jump simulation, and the Heston and Fourier material named in the folder title was missing. Regenerated outputs therefore **differ from the published article PDF**.

- **Merton compensator** (`1 Simulations/simulate_examples.py:44-49`): with a jump log-mean of -9% and lambda = 2.2, the uncompensated jump path sat below the diffusion by construction. The drift now includes `-lambda * kappa`, with `kappa = E[e^J] - 1 = -0.0849`, which adds about +18.7% a year to the log drift. Both paths now have the same expected return. Final jump-diffusion value: 113.45 -> 136.76; the diffusion benchmark is unchanged at 132.27.
- **Sum of n jumps** (line 48): for n jumps in one step, the log-jump was `n * N(mu_J, sigma_J^2)` (std n * sigma_J). It is now `n * mu_J + sqrt(n) * sigma_J * Z`. With this seed every step has at most one jump, so the published path is unaffected by this fix. `stochastic_variance_examples.csv` is byte-identical.
- **Heston and Fourier check** (new `1 Simulations/fourier_pricing_check.py`): Heston Monte Carlo (full-truncation Euler, correlated Brownian motions, 200,000 paths x 252 steps; v0 = theta = 0.045, kappa = 3, xi = 0.32, rho = -0.7) is compared with the Heston call from the little-trap characteristic function, inverted with Gil-Pelaez. The Merton call from its characteristic function is compared with the closed-form series and an exact Monte Carlo. ATM (K = 100): Heston Fourier 9.7530 vs MC 9.7634 (SE 0.0286). Merton Fourier 10.695924 vs series 10.695924 (difference < 1e-7) vs MC 10.6920 (SE 0.0353). Every MC price lies within 0.6 SE of the Fourier price. Outputs: `1 Simulations/output/fourier_pricing_check.csv` and `1 Simulations/img/fourier_pricing_check.png`.
- `requirements.txt` now pins the versions used to regenerate the outputs (Python 3.12.10) and adds SciPy.
