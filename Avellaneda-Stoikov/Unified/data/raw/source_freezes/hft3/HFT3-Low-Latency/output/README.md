# 📊 Diagnostic outputs

`baseline_audit/` contains synthetic states and an operator diagnostic of the inherited HFT2 scalar solver, generated by `apps/audit_hft2.py` with the source hash recorded in `summary.json`.

- `samples.txt`: rates, weights and 180 state/derivative samples; consumed by `evaluate_residual`.
- `summary.json`: parameters, clipping counts and residual diagnostics.
- `cpp_residuals.csv`: independently evaluated C++ residuals and comparison errors.
- `scalar_refinement.csv`: six new positive scalar-baseline solves, with three spatial grids and two common time steps; no value clipping.

These are baseline diagnostics and initial selected-point refinement checks. They do not establish global convergence, a fitted correction, economic improvement or latency results. Python needs NumPy and Matplotlib because the imported HFT2 module loads both.
